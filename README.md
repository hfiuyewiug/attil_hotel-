# Attil Mangalore - Non Veg Hotel Website

Authentic Coastal Karnataka & Mangalorean Non-Vegetarian Restaurant Website.

## Features
- **Branded Design**: Pixel-accurate recreation of Attil Non Veg Hotel (Mangalore).
- **Animated Header Brand Logo**: Emerald light sweep and trademark pulse animations.
- **Hero Split Layout**: Organic curved wave separator showcasing high-definition Biryani & Coastal dishes.
- **Dual-Direction Moving Food Cards**:
  - **Popular Dishes Row**: Moving continuously from Right to Left (`<---`).
  - **Coastal Sea Food Specialties Row**: Moving continuously from Left to Right (`--->`).
  - Zero gaps with 4x seamless repeating tracks and hover pause.
- **Feature Bar**: 5 key quality highlights.
- **About Attil & Chef Art Card**: Brand story and "Good Food Good Mood Always!" artwork.
- **Bottom Information Bar**: Location address, direct call link, and opening hours.
- **Interactive Modals**: Full filterable Mangalorean menu, specialties showcase, and photo gallery.

## Technologies Used
- HTML5
- CSS3 (Vanilla CSS with CSS Animations & Responsive Design)
- JavaScript (Vanilla JS)
